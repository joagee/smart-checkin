# 智能签到登记助手

一个纯前端的轻量签到登记工具，适合班级、活动、值班等场景。所有数据保存在浏览器本地（localStorage），无需服务器、无需联网（仅首次加载拼音库需要 CDN）。

## 功能

- **名单管理**：粘贴导入名单，支持批量导入；名单中可直接标注请假，例如 `张三, 李四(请假:2026-09-12~2026-09-13)`
- **三种状态视图**：待签到 / 已签到 / 请假中，自动归类
- **快速签到**：双击待签到人员即完成签到，支持震动反馈
- **姓名搜索**：支持中文姓名模糊匹配，也支持拼音首字母搜索
- **长按操作菜单**：长按任意人员可
  - 📅 请假 / 销假
  - ✏️ 修改名单（改名，并同步更新其签到与请假记录）
  - 🗑️ 删除人员
- **导出交接班**：一键导出当前名单（含未结束的请假），复制发给交接人员
- **新一轮签到**：重置本轮签到状态，历史记录保留用于统计
- **每日自动重置**：跨天后自动开启新一轮，无需手动操作
- **签到时间预测**：根据近 7 天签到习惯，估算每个人的常到时间并排序

## 使用方法

直接用浏览器打开 `index.html` 即可，也可以通过 GitHub Pages 在线访问。

移动端：在手机浏览器中打开页面，长按人员卡片 0.8 秒弹出操作菜单。

## 文件结构

```
index.html   页面结构与各弹窗
script.js    DataManager（数据层）与 App（界面层）
style.css    样式
```

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无构建步骤、无框架
- 拼音首字母依赖 CDN 上的 [tiny-pinyin](https://cdn.jsdelivr.net/npm/tiny-pinyin@1.3.2/dist/tiny-pinyin.js)，加载失败时回退到本地简易映射
- 数据均存储在浏览器本地，清除浏览器数据会导致名单丢失，请注意用「导出名单」备份
- GitHub Pages 对静态资源有 10 分钟缓存，`index.html` 通过 `script.js?v=N` 的版本号强制刷新脚本；修改 `script.js` 后请把版本号加一
